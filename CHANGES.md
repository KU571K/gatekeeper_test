# Что изменилось в привратнике

## Ход

Было. Студент присылал только свободное описание. Если текста хватало на пять полей, сразу показывался расклад. Если нет, задавались вопросы, затем расклад. Дальше можно было нажать «ОК» или оставить один комментарий до 400 символов. Комментарий по делу менял поля, ерунда оставляла расклад как был. На этом сценарий заканчивался.

Стало. Вместе с описанием студент указывает ровно одну свою роль, например «фронтендер». Вопросы задаются не только когда не хватает полей, но и когда роль неясна и когда в тексте осталась категория без состава: «два факультета» без имён, заказчик без названия, требование без формулировки. То же правило действует после единственного комментария: абстрактная правка не закрывается, пока студент не назовёт конкретно. Ерунда по-прежнему расклад не меняет. Когда расклад зафиксирован, модель предлагает нужные роли. Стартовая роль входит в список, список можно исправить. После подтверждения ролей выдаётся промокод проекта из 6 символов. Это код приглашения для будущего задачника, не скидка и не ключ API. Его считает программа, не модель.

Причины оценки по-прежнему лежат в цифровом следе и на экран студента не попадают. Пояснение, зачем нужна каждая сгенерированная роль, тоже остаётся в следе.

## Поля расклада

Было. Пять полей: одна тематика из справочника, технология, ровно один тип проекта, от 1 до 3 тем внутри тематики, образ результата одной формулировкой. В тексте справочника типов уже было написано «от 1 до 3», но код хранил и принимал только один тип.

Стало. Тематика по-прежнему одна, тем по-прежнему от 1 до 3. Типов проекта теперь от 1 до 3 из тех же семи. Техническая работа по требованиям конкретного заказчика получает сразу два: технологический и проект по запросу внешнего заказчика. Четыре и больше типов разбор не принимает. К образу результата добавлены 2–4 критерия или метрики без закрытого справочника. Модель предлагает только то, что следует из текста. Пример уровня: у ии-помощника «пропускная способность» и как её заметить.

## Роли

Было. Промпт запрещал спрашивать про команду, роли и число участников. В проверке правил этот шаг был явно пропущен.

Стало. На старте одно текстовое поле роли, без справочника и без списка команды. Если в строке две функции или роль слишком общая, сначала задаётся вопрос. Полный список нужных ролей появляется только в конце, от 1 до 6 предложений модели, после правки студента не больше 8. Если модель забыла стартовую роль, она добавляется в список.

## Экран

Было. Слева описание, вопросы, пять полей расклада, «ОК» или комментарий. Справа проверка правил. Кнопки примеров «Мало данных», «Технологический» и «Заказчик» подставляли готовые описания. Они остались.

Стало. На стартовой форме добавлено поле роли. В раскладе под итогом показаны критерии, под типами — цель каждого. После комментария с абстракцией появляется форма уточнения. Затем редактируемый список ролей и промокод. Правая колонка проверяет одну стартовую роль, снятие абстракций, критерии, правку ролей и выдачу промокода.

## Публикация

Было. Приложение запускалось только локально. Ключ читался из `.env`. В `.gitignore` были только `.env`, виртуальное окружение и кэш Python.

Стало. Приложение готово к Streamlit Community Cloud: `requirements.txt`, `runtime.txt` с Python 3.12, `.streamlit/config.toml`. Ключ на сервере берётся из секретов Streamlit, локально по-прежнему из `.env`. В git не попадают `.env`, `secrets.toml`, ключи, сертификаты и файлы учётных данных.

## Запуск

Было. Инструкция и виртуальное окружение были собраны на macOS: `python3`, `source .venv/bin/activate`, `cp`. Файл окружения указывал на Python из `/Library/Frameworks`.

Стало. Окружение пересобрано на Windows Python 3.14. Зависимости те же и без отдельных macOS-колёс: Streamlit, httpx, pydantic, python-dotenv. Запуск описан командами PowerShell. Если команда `streamlit` не находится, окружение не активировано. Тогда из папки проекта: `.\.venv\Scripts\Activate.ps1`, затем `streamlit run app.py`. Чтобы не открывался системный браузер: `streamlit run app.py --server.headless true`, а адрес из терминала открыть через Simple Browser в Cursor.
